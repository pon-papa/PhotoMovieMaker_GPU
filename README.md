# PhotoMovieMaker GPU

Windows 11 で、写真フォルダーから記念映像（MP4）を作る小型GUIアプリです。

バージョン: v0.1（初版）

## 初版仕様

- 画像をファイル名の自然順で並べる
- 初期値は **8秒ごとに次の写真へ**
- ゆっくりランダム方向へパン
- 徐々にズームイン
- 写真間は初期値1秒クロスフェード
- 縦写真は「ぼかし背景 + 写真全体表示」
- BGMを **開始画像～終了画像** の単位で指定
- BGM区間の境目では、前曲をフェードアウトしながら次曲をフェードイン
- NVIDIA NVENC を自動検出し、利用できる環境ではGPUエンコードを優先
- NVENCが使えない場合はCPU x264へ自動フォールバック
- 1920x1080 / 3840x2160
- 24 / 30 / 60 fps

## 使用技術

| 用途 | 使用するもの |
| --- | --- |
| GUI | Python 標準の Tkinter (ttk) |
| 画像の読み込み・EXIF回転・リサイズ・背景ぼかし | Pillow |
| フレームのパン／ズーム、クロスフェード合成 | OpenCV + NumPy |
| 動画エンコード、BGM合成 | FFmpeg（PATH優先 / なければ `imageio-ffmpeg` 同梱版） |
| GPUエンコード | FFmpeg の `h264_nvenc`（NVIDIA NVENC） |

映像は「無音のMP4を書き出す」→「BGMを合成して最終MP4にする」の2段階で作成します。
FFmpegへは生フレーム（rawvideo / rgb24）をパイプで渡しています。

## 動作環境

- Windows 11
- Python 3.11 / 3.12 / 3.13（3.13.14 で動作確認済み）
- NVIDIA GPU（NVENC対応なら自動でGPUエンコード。無くてもCPUで動作します）

作者の確認環境:

- Xeon E5-2698 v4 ×2
- NVIDIA RTX A2000 6GB
- RAM 64GB

この構成では、まず 1920x1080 / 30fps / エンコーダ「自動」で試してください。
A2000のNVENCが検出されれば映像圧縮はGPU側で行います。
パン・ズーム処理にはOpenCVを使用し、利用可能なCPUスレッドも使います。

## セットアップ

1. Python 3.11 / 3.12 / 3.13 のいずれかをインストール
2. `setup.bat` をダブルクリック（`requirements.txt` の依存をインストール）
3. `run.bat` をダブルクリック（アプリ起動）

依存パッケージ（`requirements.txt`）:

```
pillow>=10.0
numpy>=1.26
opencv-python>=4.9
imageio-ffmpeg>=0.5
```

FFmpegは、PATH上にインストール済みのものがあればそれを優先します。
なければ `imageio-ffmpeg` の同梱FFmpegを使います。

### NVENCについて

「自動」で `h264_nvenc` が検出されればNVENCを使います。
もしNVENCが検出されない場合は、Windows用のNVENC対応FFmpegを別途インストールして
PATHを通せば利用できます。

## 対応ファイル

- 画像: `.jpg` `.jpeg` `.png` `.webp` `.bmp` `.tif` `.tiff`
- 音声: `.mp3` `.wav` `.m4a` `.aac` `.flac` `.ogg`

## 画面の設定項目

| 項目 | 範囲 | 初期値 |
| --- | --- | --- |
| 写真の間隔 | 2～30秒 | 8.0秒 |
| 写真クロスフェード | 0～4秒 | 1.0秒 |
| ズーム量 | 0～20% | 8% |
| 解像度 | 1920x1080 / 3840x2160 | 1920x1080 |
| FPS | 24 / 30 / 60 | 30 |
| エンコーダ | 自動 / NVENC / CPU x264 | 自動 |
| 縦写真も切らずに見せる（ぼかし背景） | ON / OFF | ON |
| 曲間フェード（BGM区間ごと） | 0～10秒 | 2.5秒 |

作成中は進捗バーが表示され、「中止」ボタンで途中停止できます。

## BGM区間の指定例

写真が

- IMG_0001.jpg ～ IMG_0032.jpg
- IMG_0033.jpg ～ IMG_0068.jpg
- IMG_0069.jpg ～ IMG_0105.jpg

なら、

- IMG_0001 ～ IMG_0032 = 曲A
- IMG_0033 ～ IMG_0068 = 曲B
- IMG_0069 ～ IMG_0105 = 曲C

のように登録できます。

「曲間フェード」を2.5秒にすると、曲BはIMG_0033の開始時刻より少し前から
静かに入り始め、その間に曲Aがフェードアウトします。

補足:

- BGM区間どうしを重ねて指定することはできません（事故防止のためエラーになります）
- BGMが区間より短い場合は自動でループします
- 音声は AAC 256kbps で書き出します

## 最初に勧める設定

- 写真の間隔: 8.0秒
- 写真クロスフェード: 1.0秒
- ズーム量: 8%
- 解像度: 1920x1080
- FPS: 30
- エンコーダ: 自動
- 曲間フェード: 2.5～3.0秒

150枚なら約20分です。

## 注意

初版では人物の顔認識まではしていません。
そのためパン方向は「上品に見えやすい方向セット」から選びます。
パン方向は固定シードで決めているため、同じ素材なら同じ結果になります。
